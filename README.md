# ☕ Roast & Co. – Coffee Shop Web Application

## 📌 Project Overview
Roast & Co. is a fully functional coffee shop e-commerce web application developed to provide customers with a simple and user-friendly online shopping experience. Users can explore different coffee categories, browse products, add items to their cart, and place orders.

The application includes an admin section to manage products, categories, and customer orders.

## 🎯 Project Objectives
- To develop an interactive and user-friendly coffee shop website.
- To provide online browsing and ordering facilities.
- To manage products, categories, users, and orders efficiently.
- To implement database connectivity using PHP and MySQL.
- To gain practical experience in full-stack web development.

## ✨ Key Features

### 👤 User Module
- User registration and login.
- Browse coffee products and categories.
- View product details.
- Add products to the shopping cart.
- Manage cart items.
- Place orders.

### 🔐 Admin Module
- Admin login.
- Manage product categories.
- Add, update, and manage products.
- View and manage customer orders.
- Manage customer information.

## 📂 Project Structure

- `images/` – Website images and product images.
- `uploaded_img/` – Uploaded product images.
- `config.php` – Database connection.
- `index.php` – Homepage.
- `category.php` – Product categories.
- `cart.php` – Shopping cart.
- `about.php` – About page.
- Other PHP files – User and admin functionalities.

## ⚙️ How to Run the Project

1. Install XAMPP on your computer.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Open phpMyAdmin.
5. Create the required database and import the project SQL file.
6. Update the database connection details in `config.php`.
7. Open your browser and visit:

   `http://localhost/procoffee/`
